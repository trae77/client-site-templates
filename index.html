trae77 / client-site-templates

Small-business one-pager templates

Eight polished, self-contained HTML/CSS/JS sites. Pick a niche, customize branding, deploy. No build step required.

Product ladder

Two steps. A prospect starts on a static one-pager and can step up to an owner login and estimates. Pricing is not set — nothing in this repo or in Big Foot states a price for these tiers.

  1. One-pager The static templates and the mockup generator. A public homepage. No login, no database. This is what GitHub Pages serves.
  2. Owner login + estimates Optional Node addon in upgrade/. The same one-pager stays the public homepage, and a logged-in owner gets an estimates page. Needs a Node host. GitHub Pages cannot run it.
