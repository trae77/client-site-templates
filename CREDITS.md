# Credits and image licenses

- **Original templates** (`pressure-washing/`, `landscaping/`, `plumbing/`, `cleaning-service/`, `restaurant/`, `auto-detailing/`, `handyman/`, `generic-business/`) hotlink photos from [Unsplash](https://unsplash.com) under the [Unsplash License](https://unsplash.com/license) (free to use, no attribution required). Picsum placeholders in those files are stripped by the generator.
- **Library categories** (`tools/library.mjs`) use **no stock photos**. Samples built from the original templates (e.g. `samples/landscaping/`, `samples/cleaning/`, `samples/restaurant-*`, `samples/plumbing/`) keep those templates' Unsplash photos, listed below. No page uses a stock photo as `og:image` (none of the templates set og:image). Photo, before/after and gallery tiles are CSS gradient placeholders; theme patterns are inline SVG written for this repo.
- **Maps** (`map` feature) embed [OpenStreetMap](https://www.openstreetmap.org/copyright) tiles, © OpenStreetMap contributors (ODbL); the attribution line is printed under each map. Geocoding (only when `--map-center` is not passed) uses the free Nominatim service at build time.
- Client photos passed with `--before-after` are the client's own and are copied into the mockup's `img/` folder.
- `widgets/order/` and `tools/sample-data/` are written for this repo; there are no images in them.

## Local stock photos (`stock/`)
Downloaded once and committed so builds don't hotlink. Used only in the gallery of library categories that would otherwise show grey "Photo placeholder" tiles. Each one is captioned **"Stock photo"** on the page, with alt text "Stock photo N (not <Business>'s work)", and the gallery note says they are stock photos, not the business's work. They are never presented as the client's projects. Swap them for the client's own photos before launch.
