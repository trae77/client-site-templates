# Logo & Brand Kit: getting to pro level (research, 2026-10-22)
Prices unchanged: $350, or $250 with a site.

## 1. What a pro kit includes
Sources: [ArtVersion checklist PDF](https://artversion.com/wp-content/uploads/2026/03/Brand-Identity-Design-Checklist-ArtVersion.pdf), [Markuva 2026 checklist](https://markuva.com/blog/what-to-include-brand-guidelines), [Shopify brand guidelines](https://www.shopify.com/blog/brand-guidelines), [HubSpot style guide PDF](https://www.hubspot.com/hubfs/How%20to%20Create%20a%20Brand%20Style%20Guide.pdf)
- Logo suite: primary lockup, horizontal/secondary, stacked, icon/symbol (favicon, social avatar); full color, one-color black, all-white/reversed
- Files: SVG + EPS/PDF (vector), transparent PNG, JPG/WEBP; favicon set (16/32/180/512 + .ico)
- Color: primary/secondary/accent/neutrals with HEX, RGB, CMYK (Pantone optional), usage ratio (60-30-10), WCAG contrast pairs
- Type: heading + body font with license source, weights, size hierarchy, web fallbacks
- Guidelines PDF: clear space, minimum size, approved backgrounds, misuse ("don'ts"), voice/tone, imagery style
- Applications: social templates (profile, cover, post), business card (print-ready w/ bleed), email signature, letterhead/invoice optional

## 2. Pro workflow
1. Discovery questionnaire (audience, competitors, 3 adjectives, likes/dislikes, uses: signs, trucks, shirts)
2. Moodboard (competitor scan + references) — Excalidraw/Figma board
3. 3 distinct concepts shown in mockups (sign, truck, phone, card) — not a grid of AI options
4. 2 revision rounds (state in scope)
5. Final: hand-rebuilt or cleaned vector in Figma/Inkscape (never ship raw AI raster or auto-trace without cleanup)
6. Export suite + guidelines PDF + templates; QA checklist (sec. 4)

AI-logo caution: purely prompt-generated images are not copyrightable in the US ([Copyright Office guidance](https://copyright.gov/ai/ai_policy_guidance.pdf); [Part 2 report](https://www.copyright.gov/ai/Copyright-and-Artificial-Intelligence-Part-2-Copyrightability-Report.pdf)) — human redrawing/modification is protectable. Trademark rights come from use in commerce; AI isn't disqualifying, but generators can produce look-alikes and template tools (Looka/Canva templates) aren't exclusive. Rule: use AI for ideas, redraw the final mark by hand in vector, avoid stock template elements, and give client a written assignment of rights.

## 4. Quality bar / QA checklist
- [ ] Readable at 16px favicon and on a truck at 50 ft
- [ ] Works in one color (black, white) and reversed
- [ ] Legible type, no thin hairlines; kerning fixed by hand
- [ ] Distinctive vs top 5 local competitors; not a template/clip-art
- [ ] Clean vector: few nodes, no stray points, outlined text, no embedded raster
- [ ] Contrast pairs pass WCAG AA
- [ ] Fonts licensed (Google Fonts OFL) and listed
- [ ] USPTO search: [tmsearch.uspto.gov](https://tmsearch.uspto.gov/) for name + design codes ([Design Code Manual](https://tmdesigncodes.uspto.gov/alpha)); no image reverse-search, so also do Google reverse image search. Not legal advice; client should consult attorney before filing.

## 5. Recommendation for William
1. Intake form (Google Form) + 20-min call.
2. Agent builds moodboard + competitor scan (Excalidraw/Figma).
3. AI image gen / Brandmark for 15–20 rough ideas → William picks 3 → redraw cleanly in Figma/Inkscape (vectorizer.ai only as starting trace).
4. Present 3 concepts on mockups via Hcti/Canva; 2 revision rounds.
5. Export suite with a script (SVG→PNG sizes, favicon set, PDF) — Inkscape CLI.
6. Guidelines PDF (8–12 pages) from an HTML template → PDF; Canva Brand Kit + templates for client.
7. Optional: hire a Fiverr designer ($50–100) for the mark when a client wants illustrative/mascot work.

Tool budget: $0 core (Figma, Inkscape, Google Fonts, Coolors) + Canva Pro $12/mo + vectorizer.ai $9.99/mo only in months with a job ≈ $22/mo max. (Needs William's OK for any paid account.)

Deliverable package (zip + shared Canva):
- /logo: primary, horizontal, stacked, icon × color/black/white — SVG, PDF, PNG (transparent, 3 sizes)
- /favicon: .ico, 16/32/180/512 PNG
- brand-guidelines.pdf (logo rules, clear space, min size, don'ts, colors HEX/RGB/CMYK, fonts, voice)
- /social: profile pic, FB/LinkedIn covers, 3 post templates
- business-card print PDF (bleed) + email signature HTML
- rights-transfer note + font license list
